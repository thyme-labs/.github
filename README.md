# Thyme Labs on GitHub

The organization profile lives in [profile/README.md](profile/README.md) and is displayed at [github.com/thyme-labs](https://github.com/thyme-labs).

Brand assets are in `profile/assets/`:

- `hero.svg` is the editable banner source; lettering is outlined so it does not depend on installed fonts.
- `hero.png` is the 2400 × 990 banner used in the profile.
- `avatar.png` is the opaque 512 × 512 square organization avatar, ready to upload in GitHub organization settings. Its dark background fills every corner; GitHub applies its own corner rounding.
- `logo.svg` is the full main logo; `gate.svg`, `atlas.svg`, and `flow.svg` are the product icons.

The organization avatar and pinned repositories are configured through GitHub's website. Update the avatar under **Settings → Profile** and pin **sdk** and **flow-template** from the organization overview.
