### Build with Flow

- **[SDK & CLI](https://github.com/thyme-labs/sdk)** — Write tasks, run them locally, simulate contract calls and upload your code.
- **[Starter template](https://github.com/thyme-labs/flow-template)** — Start with example tasks, CLI configuration and instructions for coding agents.

```sh
npm install -g @thyme-labs/cli
thyme init my-app
```

Follow the **[quickstart](https://flow.thymelabs.io/docs/getting-started/quickstart)** to run your first task and configure an executable.
